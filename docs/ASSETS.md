# Asset provenance

All neighborhood geometry is generated by local source in `frontend/Scene.tsx` and `backend/topology.py`. No external photographic textures, real inspection footage, remote font, customer data or maps are used. The two user-provided concept images were visual references only and are not bundled as application screenshots or evidence.

Icons are from `lucide-react` (ISC license); React, Three.js, React Three Fiber/Drei, Vite and FastAPI are open-source dependencies. Their license files remain in the installed packages. OpenCV is distributed under Apache-2.0. The lockfiles identify the exercised package versions.

Test/evaluation images are created by OpenCV from projected approved paths and an independently added test line. They are labeled pixel fixtures and do not substitute for actual scene-derived inspection verification. No rendered scene screenshot or live-capture sample is claimed in this handoff.
